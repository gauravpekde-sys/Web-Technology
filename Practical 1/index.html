Overview of Web Basics

HTML

HTML is used to create the basic skeleton of any website. It uses tags to display headings, paragraphs, images, links, and forms on the screen.

CSS

CSS is used to style web pages. It controls colors, font sizes, spacing, and layouts so the page looks neat and organized.

JavaScript

JavaScript is a scripting language used to make web pages interactive, such as handling button clicks, validating form inputs, and showing alerts.
